LE PRINCIPE

Une app de rencontre spontanée a 2 besoins, pas forcément les mêmes gens : le CARBURANT de densité (nombreux, même lieu, même heure, souvent) et le REVENU (ceux qui paient). On amorce avec l'un, on monétise avec l'autre.

Analyse complète (matrice 4 segments × 4 critères) : docs/cible-analyse.md.

Les 3 insights
  1. Étudiants EPFL/UNIL (35k) = le carburant (denses + viraux), mais faible pouvoir d'achat → pas le portefeuille.
  2. Expats / nouveaux arrivants = la pépite de douleur (besoin aigu de rencontrer, paient), mais besoin d'anglais (i18n) → Phase 2.
  3. Jeunes actifs + expats + 30+ = le revenu, une fois la densité créée par les étudiants.
✅ RECO

Beachhead = étudiants (amorcer la densité) → monétiser via actifs + expats. On séquence, on ne choisit pas densité OU revenu. Pivot vers actifs/expats si la rétention étudiante est faible (à surveiller dès le 1er test).

🧪 Test <30j pour valider la cible

Soirée chorégraphiée sur 1 campus → mesurer dispo / Clutchs envoyés / vrais RDV / retour la semaine d'après (rétention M1). + 5-10 interviews (étudiant vs actif vs expat) : qui a le plus mal, qui paierait, qui se sent en sécurité.

💳 Modèle de prix (direction David)

Multi-paliers : ~2 abos (entrée + intermédiaire) + 1 palier VIP cher chargé de fonctionnalités. ⚠️ Garde-fou : auditer l'impact équilibre H/F de chaque feature VIP avant de coder — jamais de pay-to-play qui force l'attention d'une femme. Prix d'entrée à tester (9.90/14.90/19.90).
