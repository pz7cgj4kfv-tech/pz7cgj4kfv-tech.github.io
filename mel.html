🎬 Une animation / un écran
  1. Dans le Canvas, clique « Copier » (tout le code).
  2. Colle-le dans ton message à David (WhatsApp/mail — c'est juste du texte).
  3. Ajoute une petite vidéo d'écran de l'anim qui bouge + son nom (« le Verrou », « célébration »…).
🔘 Un bouton / une icône
  1. Exporte-le en SVG (parfait : net à toutes les tailles, recolorable).
  2. Si ça remplace un bouton existant → garde le même nom (échange direct).
  3. Si c'est nouveau → un nom clair (ex. bouton-verrou, icone-event).
  4. Dis-moi juste : « ça remplace X » ou « c'est un nouveau ».
