Procédure de test — flow complet

💡 Astuce : utilise Safari sur ton iPhone pour le compte Mel, et un onglet privé Chrome (ou ton ordi) pour le compte Ami. Les deux en même temps.

1
Se connecter (compte Mel)Safari → pz7cgj4kfv-tech.github.io/app → email mel@clutch.app / Mel2026!
2
Compléter l'onboardingPrénom déjà rempli. Genre → Âge → Photo (optionnel pour tester) → Intérêts
3
Se mettre disponibleChoisir heure + lieu à Lausanne. Le toggle "Disponible" s'allume. Tu apparais dans Discover.
4
Ouvrir l'onglet AmiOnglet privé Chrome → même URL → ami@clutch.app / Ami2026! → onboarding → se mettre dispo aussi
5
Envoyer un Clutch (depuis Mel)Discover → profil Ami → Clutcher → choisir café Lausanne → heure → message → Envoyer
6
Recevoir le Clutch (depuis Ami)Inbox → "Nouveau Clutch de Mel" → voir lieu/heure → Accepter (ou contre-proposer une autre heure)
7
Chat entre les deuxAprès acceptation → Chat → max 5 messages chacun avant le RDV. Compter combien ça suffit.
8
Annuler (tester le score)RDV → Annuler → score de Mel baisse -10pts. Vérifier dans Profil.
9
Feedback post-RDVAprès la durée du RDV → écran Feedback → Super / OK / Lapin / Fantôme → voir impact sur score.

Système de fiabilité — à tester

Score de fiabilité (0–100%)

⭐ Super RDV (feedback positif)+3 pts
🐇 Lapin (retard, prévenu tard)−5 pts
👻 Fantôme (no-show sans prévenir)−15 pts
❌ Annulation directe du RDV−10 pts

Paliers de suspension automatique

Score < 60%Pause 3 jours
Score < 40%Pause 14 jours
Score < 20%Pause 60 jours
Score = 0%Ban permanent

→ Pendant la suspension : profil invisible dans Discover, impossible de se remettre disponible. Un banner rouge le signale dans l'app. Comptes admin (Mel, TestClutch) sont exempts.
